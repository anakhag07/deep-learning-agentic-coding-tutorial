# Visualize an experiment

- Use matplotlib and save a PNG; use the Agg backend for batch jobs.
- Give each panel a concise title and label both axes. Show the metric needed to interpret the result.
- For comparisons, keep axis limits and colors consistent. Print the saved path and inspect the image.
